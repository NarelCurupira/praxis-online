ORDEM DE INSTALAÇÃO

1. Faça backup do banco no Supabase.
2. Execute no Supabase SQL Editor:
   supabase/migrations/20260725_praxis_v010_confiabilidade.sql
3. Somente após o SQL terminar sem erro, substitua no GitHub todos os arquivos deste pacote, preservando os caminhos.
4. Aguarde a publicação do Cloudflare Pages.
5. No GitHub, abra a aba Actions e confirme que “Qualidade do Práxis” concluiu com sucesso.
