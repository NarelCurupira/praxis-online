PRÁXIS WEB 0.10.3 — PWA, BIOMETRIA E DESEMPENHO

INSTALAÇÃO
1. Faça backup externo do banco.
2. Substitua no GitHub todos os arquivos deste pacote, preservando os caminhos.
3. Não há migração SQL nesta versão.
4. O package.json fixa @supabase/supabase-js em 2.105.4. O arquivo .npmrc faz o ambiente ignorar temporariamente o package-lock antigo durante esta atualização.
5. Como a dependência mudou, permita que o ambiente execute npm install. O workflow incluído usa npm install, e não npm ci.
6. Configure as passkeys no Supabase conforme SUPABASE-PASSKEYS.md.
7. Aguarde a publicação do Cloudflare Pages.
8. No navegador, atualize uma vez para registrar o Service Worker.

TESTE RECOMENDADO
- Abra o Práxis no Mac ou celular.
- Entre com e-mail e senha.
- Vá a Sobre → Acesso por biometria.
- Ative a credencial.
- Saia da conta e teste “Entrar com Face ID/Touch ID/biometria”.
- Instale o PWA quando o aviso aparecer.
- Recarregue a página e confira o Diagnóstico para comparar app.reloadAll e movements.reload.

DESEMPENHO
A consulta principal agora:
- usa a sessão local já validada, evitando chamadas repetidas a auth.getUser;
- solicita apenas os campos necessários;
- consulta a primeira página com contagem e busca as páginas restantes em paralelo;
- compartilha a consulta de feriados entre o carregamento de dados e as Configurações;
- evita chamadas duplicadas simultâneas.
