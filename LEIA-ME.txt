PRÁXIS WEB 0.9.1 — USABILIDADE DAS TABELAS

Este pacote contém arquivos completos, prontos para substituir no GitHub.

ORDEM DE INSTALAÇÃO

1. Faça um backup do banco.
2. No Supabase > SQL Editor, execute integralmente:
   supabase/migrations/20260725_praxis_v091_usabilidade_tabelas.sql
3. Depois, substitua no GitHub todos os arquivos deste pacote, preservando os caminhos.
4. Aguarde a publicação do Cloudflare Pages.
5. Recarregue o Práxis sem cache.

ALTERAÇÕES PRINCIPAIS

- correção do posicionamento das setas de paginação;
- paginação fora da área de rolagem horizontal;
- paginação ocultada quando não há resultados;
- mensagens amigáveis para fila vazia e filtros sem resultado;
- retirada da coluna Responsável da aba Minha fila;
- rótulos visíveis para todos os filtros;
- separação visual entre filtros e ordenação;
- ordem descrita em linguagem natural, como “Mais próximo primeiro”;
- datas compactas no formato DD/MM/AA nas tabelas;
- data completa e horário exibidos ao repousar o cursor;
- nome curto configurável para o responsável na aba Equipe;
- tamanho da letra configurável por usuário;
- densidade compacta, confortável ou espaçosa;
- preferências de letra e densidade gravadas no navegador;
- marcadores dos filtros ativos e comando para limpar todos;
- páginas Minha fila e Processos usando melhor a largura disponível;
- primeira e última página adicionadas à paginação;
- versão atualizada para 0.9.1.

OBSERVAÇÃO

O nome de exibição é usado apenas nas tabelas e filtros compactos. O nome completo
permanece nos relatórios, na auditoria e na administração da equipe.
