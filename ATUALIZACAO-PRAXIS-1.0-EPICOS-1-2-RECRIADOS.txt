PRÁXIS 1.0 — ÉPICOS 1 E 2 RECRIADOS

Esta versão substitui integralmente o pacote anterior dos Épicos 1 e 2.

IDENTIDADE
- O símbolo oficial agora é RASTER, derivado diretamente do P aprovado.
- Não há SVG da marca neste pacote.
- praxis-1-mark.webp: símbolo principal.
- praxis-1-logo-light.webp: lockup para superfícies claras.
- praxis-1-logo-dark.webp: lockup para superfícies escuras.
- symbol-light.webp e symbol-dark.webp preservam o contrato de regressão do projeto,
  mas usam o novo P do Práxis 1.0.

ÉPICO 1 — FUNDAÇÃO VISUAL
- Product Design Tokens.
- Light mode e Dark mode.
- Escala de espaçamento 4/8.
- Tipografia, raios, elevação, foco, cores semânticas.

ÉPICO 2 — PRODUCT SHELL
- Sidebar desktop Práxis 1.0.
- Sidebar recolhida com símbolos por tema.
- Topbar compacta.
- Safe area do iPhone preservada.
- WorkspaceSwitcher integrado.
- Bottom navigation mobile:
  Início · Fila · Processos · Central · Perfil.
- A Central é aberta sem alteração do App.tsx.

NÃO ALTERADO
- App.tsx.
- Supabase / SQL / RLS.
- Push.
- contingência / IndexedDB / sync_queue / conflitos.
- MFA / passkey.
- regras de negócio.

IMPORTANTE
Recomendação: criar uma NOVA branch a partir do main para aplicar este pacote.
Assim os SVGs defeituosos do pacote anterior não permanecem no histórico da PR.
