# Atualização para o Práxis 0.10.7.2

Esta é uma revisão exclusivamente visual da versão 0.10.7.

## Instalação

1. Extraia o ZIP na raiz do repositório.
2. Autorize a substituição dos arquivos existentes.
3. Envie as alterações ao GitHub.
4. Aguarde o workflow e a publicação do Cloudflare Pages.
5. Reabra o PWA para ativar o novo cache.

Não é necessário executar query no Supabase.
